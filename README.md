# AgentVerse

## Quick start (one command)

`run_pipeline.ps1` runs the entire flow below in one go: creates/reuses `.venv`,
installs dependencies only if missing, transcribes every video in a folder you
give it, waits for you to run the Orchestrator Agent in Copilot Chat, then
builds (or serves) the site.

```powershell
.\run_pipeline.ps1 -VideoFolder "C:\path\to\downloaded\videos" -Model small -Serve
```

- `-VideoFolder` — folder containing all the downloaded videos to transcribe (required).
- `-Model` — Whisper model size: tiny/base/small/medium/large (default: base).
- `-Serve` — run `mkdocs serve` at the end instead of `mkdocs build`.

The script pauses partway through so you can invoke the Orchestrator Agent in
Copilot Chat (that step is LLM-driven and can't be run from a shell script) —
press Enter in the terminal once it has finished publishing before continuing.

## Manual steps (what the script does under the hood)

### Install Python dependencies
```
python -m venv .venv
```
```
.\.venv\Scripts\pip install -r "path_to_requirements_file"
```

### Transcribe (base model is fast; use --model small for better accuracy)
```powershell
.\.venv\Scripts\python pipeline/transcribe.py "downloaded_video_path"
```

### Run the Pipeline
select the orchestrator agent and give the prompt to process the pending transcript (that will be generated by the above step )

### Build the website
```powershell
.\.venv\Scripts\mkdocs serve
```
