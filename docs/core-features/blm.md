# Bureau of Land Management (BLM) Compliance

## Overview

Bureau of Land Management (BLM)Compliance FLOWCAL includes several features available to help operators meet the requirements of 43 CFR §§ 3170, 3173, 3174 and 3175—the replacement rules for BLM Orders 3, 4 and 5. BLM Tab Each editor in FLOWCAL contains a BLM tab to capture data for meters, locations, tanks and caverns that are under BLM jurisdiction.

## Key Characteristics

- To designate an item as a BLM property, click the BLM tab and select "Yes" from the BLM Property drop-down.
- Several regulatory identification fields on the BLM tab become active when the meter or location is designated as a BLM property.
- These include Facility Measurement Point (FMP) Number, Lease Number, and CA and PA Numbers.
- You can also set the BLM Property designation and other BLM-specific fields using FcLoader.
- The following meter reports include the BLM identification fields: BLM GVS Meter Sample and Analysis Meter Edit Reasons Meter Characteristic Meter Alarm Detail Meter Events FMP Tier The daily average flow for a facility measurement point (FMP) determines the required frequency for inspection and permissible measurement uncertainty, and influences several other applicable practices.
- Each FMP is assigned to a volume tier based on the daily average flow calculated from the previous 12 months of data.
