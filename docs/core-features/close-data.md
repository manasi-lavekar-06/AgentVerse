# Close Dates Editor

## Overview

Close Dates Editor The Close Dates Editor displays the following close status information for a specified meter: Months for which the meter is closed Whether the meter is still closed or has been reopened Whether PPAs have been applied The start and end of the closed month When the month was last closed or opened Who last closed or opened the meter for that month To view meter close dates: Go to Setup Meter Close Dates . Select a meter number or meter name from the drop-down menu.

## Key Characteristics

- To view data for the meter for a range of months, select Contract Month and select the time frame to be displayed; otherwise, select All Dates .
- Click Refresh .
- Meter Close Date Considerations Once a meter’s information is displayed in the editor, if a month has been closed, but no PPAs have been applied, the user can select the row for that month and click Open Data.
- This will open the month and any edits to the data will be saved as regular edits, not as PPAs.
- Who opened the data and when they opened it will be recorded and displayed under Open/Closed By and Open/Closed On, respectively.
- If a meter has been opened for a month, it can be closed by selecting the row for that month and clicking Close Data.
