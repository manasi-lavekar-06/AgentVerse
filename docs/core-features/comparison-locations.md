# Comparison Location Editor

## Overview

ComparisonLocation Editor Back | Configuration | Validation Configuration Tab The following items are available on the Configuration tab: Check and Custody object selectors - Select designations for the check and custody measurements. They may be meters, locations or a mix of the two.

## Key Characteristics

- Calculation - Define the calculation used to provide the comparative amount and percentage.
- This is not an absolute value.
- To define the comparison calculation, set the numerator to determine the difference.
- The choices are either: (Check - Custody) or (Custody - Check).
- This essentially determines the sign of the result.
- Positive values represent the user's maximum validation, while negative values represent the user's minimum validation.
