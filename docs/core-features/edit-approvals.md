# Edit Approvals

## Overview

Edit Approvals Use the Edit Approvals screen to approve, reject, or un-reject pending edits, prior period adjustments, and applied test reports. When edit approval limits are defined under System Configuration, monthly adjustments that exceed the specified volume or energy limit will require approval before the edit can be applied.

## Key Characteristics

- Quality source apply and auto edits are not considered during calculation if edits have exceeded the edit approval limit.
- When the PPA options are set to "Approval Required", any prior period adjustments will require approval before they are applied.
- When test reports using TESTit Integrated are applied, approval is required before any edits are applied.
- Viewing Records To view records: Go to Review Approvals .
- Select a list, location, or meter.
- Select a time filter.
