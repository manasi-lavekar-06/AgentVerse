# Measurement Glossary

## Overview

Measurement Glossary Absolute Pressure Atmospheric Pressure + Gauge Pressure ACBI Automatically Created Batch Upon Import AGA-7 Calculation Method American Gas Association method for calculating gas flow for a linear meter Ambient Conditions The conditions (pressure, temperature, humidity, etc.) of the medium surrounding an object such as the case of a meter, instrument, transducer, etc. Analysis Reports Analysis reports allow the user to identify analysis information that has been applied to a meter AP0 Atmospheric Pressure Zero API Gravity A term used to express the relative density of petroleum liquids.

## Key Characteristics

- API gravity is measured by a hydrometer instrument having a scale graduated in degrees API.
- Application Process The application process provides security options that affect all processes across the FLOWCAL application Atmospheric Pressure The pressure exerted by the weight of the atmosphere at the meter’s location.
- At sea level, the pressure is approximately 14.7 psi (101 kpa), often referred to as 1 atmosphere Auto Rescan Auto Rescan is a service that allows FLOWCAL check for missing data on meters and quality sources.
- Base Conditions The conditions of temperature and pressure to which measured volumes are to be corrected.
- Defined in FLOWCAL as the system pressure and temperature base.
- Base Density Determined from the density at flowing conditions by applying the density meter factor (DMF) to account for densitometer inaccuracies and then accounting for the temperature and pressure of the density measurement not being at base temperature and pressure Batch Used in liquids only.
