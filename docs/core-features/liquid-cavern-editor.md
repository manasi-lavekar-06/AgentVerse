# Liquid Cavern Editor

## Overview

Liquid Cavern Editor The Liquid Cavern Editor requires a Liquids Inventory Module license. Liquid caverns can be added to locations to track total inventory and perform gain/loss calculations.

## Key Characteristics

- Use the Liquid Cavern Editor to calculate inventory totals for liquid volumes.
- To access the Cavern Editor: Go to Open Liquid Cavern Editor .
- When you create a new liquid cavern, a reference meter, along with either an injection or withdrawal point, must be specified before the meter can be saved.
- Reference Meter - A reference meter is required upon creation of a new cavern.
- The contract day and hour from the reference meter will be used to calculate the rollup IDs for cavern tickets.
- Injection Point - An existing station location specified as the inlet to the cavern.
