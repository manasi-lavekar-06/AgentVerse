# PPA Editor

## Overview

PPAEditor Use the PPAEditor to apply a volume, energy and/or mass adjustment to a specific datetime range, contract day(s), or a contract month after meter data has been closed.Once the PPAis applied, the data will then be saved to the PPAcolumns within the database. The PPAEditor can also be used to review PPAs for gas and liquid meters and create PPAs for gas meters.

## Key Characteristics

- To access the PPAEditor, go to Open PPA Editor .
- A list of existing PPAs for a selected meter will display.You can select a range of rows and right-click to display the cumulative PPAamounts.
- Use the Time Filter radio buttons to narrow the PPAs displayed to a particular month range based on production month or accounting month.
- If you select a list or location, you can scroll through the meters to see any PPAs.
- To create a new PPA: Click the New button.
- Select the desired date range and meter.
