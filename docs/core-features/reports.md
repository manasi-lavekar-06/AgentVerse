# Add an Export

## Overview

Add an Export Quorum develops custom exports to extract data from FLOWCALand output it into a text file, such as a TXT or CSV file, that can then feed other systems or be sent to other companies for import. After a custom export has been created, you can add it to FLOWCAL and run it manually from the Exports menu or run it automatically by creating an export schedule from Report/Export Scheduling .

## Key Characteristics

- An export does not need to be added to FLOWCAL if you will only run it manually from the Reports Exports menu.
- You will only need to add the export to FLOWCAL if it will be scheduled.
- To add a custom export to FLOWCAL: Copy the export file ( .dll ) into the Export directory under the FLOWCAL installation folder everywhere FLOWCAL is installed.
- In FLOWCAL, go to Reports Add Export .
- The Select an Export screen will display.
- FLOWCAL will attempt to default to the Export folder; if this directory does not display, you will need to navigate to the Export folder located in the FLOWCAL installation folder.
