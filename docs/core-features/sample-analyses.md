# Analysis Overrides

## Overview

*** This topic needs internal review. *** Analysis Overrides Standalone samples are also used in FLOWCAL in an operation called Sample Override.

## Key Characteristics

- The user can do a Sample Override on Meter Batches and Standalone Tickets.
- A meter or location can be assigned to have an LQ applied, but the user can choose to do a sample override and assign a specific standalone sample to a meter batch or a liquid inventory or tank location.
- Apply Sample to a Batch To perform a sample override on meter batch tickets, select one or more batches from the Volume Editor, right-click and hover over the Batch menu item, then select Sample Override.
- A Sample Assignment Window will appear where the user can choose between Source Quality analyses, or Sample Quality analyses.
- To apply a sample quality: Select the Sample Quality radio button.
- Choose a time frame that encompasses the sample to be applied.
