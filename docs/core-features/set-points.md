# Source Analysis

## Overview

Source Analysis The Set Points calculator requires the Validation Set Points module. Without it, you can manually enter validation parameters in the Source Editor for each source.

## Key Characteristics

- FLOWCAL uses built-in validation set points to identify data anomalies.
- These set points are based on limits imposed by various calculation standards.
- They can also be added to meters and quality sources to flag data that is outside of normal operating boundaries.
- Set points can be calculated for multiple sources at a time using the Validation Set Points calculator for Source Analysis, based on each source’s historical data.
- Validation set points are determined based on data in a specified date range and the percentage of data to be flagged.
- To ensure that valid set points are calculated, this should only be used once data has been reviewed and verified.
