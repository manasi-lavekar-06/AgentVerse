# Tank Editor - Tools

## Overview

Tank Editor - Tools Back to Tank Editor The following options are available on the Tank Editor Tools menu: Contact Selections Users can assign contacts to tanks, similarly to meters, locations, and quality sources. Assigning contacts to tanks allows for notifications based on messages and exceptions.

## Key Characteristics

- Typically, these will be generated when importing TFX files with gauge tickets and tank run tickets.
- Ticket Validations This option allows users to attach validation templates to a tank to validate attached tickets.
- See Ticket Validations for additional information.
- Info The Info screen contains the following items: Fluid Phase - The fluid phase of a tank is always "Liquid".
- Requires Close Approval - Tanks that require close approval have to satisfy a set of conditions before they can be closed, and are closed manually in Location Close Approval .
- Weekly Schedule - This drop-down will list schedules created using the Annual Schedule Editor .
