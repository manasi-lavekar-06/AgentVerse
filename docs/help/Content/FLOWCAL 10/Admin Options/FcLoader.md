# <span id="aanchor96"></span> FcLoader

FcLoader is a standalone utility used for new implementations or new assets. This utility imports tab-delimited files in a proprietary format, allowing you to create different types of data in bulk, such as companies, contacts, locations, meters, and quality sources.

The FcLoader utility can run from a command prompt or batch file. It is shipped with FLOWCAL and is executed from the FLOWCAL install folder.

The FcLoader file format is proprietary and requires a non-disclosure agreement (NDA). Contact <a href="mailto:flowcal.support@quorumsoftware.com" class="notelink">Customer Support</a> to obtain this file format.
