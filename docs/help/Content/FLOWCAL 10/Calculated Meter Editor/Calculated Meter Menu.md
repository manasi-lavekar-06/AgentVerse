## Calculated Meter Menu

The following items are available on the Calculated Meter menu:

- **New** - Create a new meter.

  A fluid phase of liquid is only available with the FLOWCAL Liquids module.

- **Edit** - Enable edit mode.

- **Delete** - Delete the selected meter. Calculated meters can only be deleted from the Calculated Meter Editor.

- **Security** - View or edit users that have access to the calculated meter.

  User/group access to calculated meters is only relevant for companies that maintain object level security. Most companies do not restrict access at the object level.

- **Exit** - Exit the screen.
