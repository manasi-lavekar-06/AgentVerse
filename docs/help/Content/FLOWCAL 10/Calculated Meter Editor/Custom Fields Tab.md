## Custom Fields Tab

The Custom Fields tab has 60 user-definable fields that can be used to add the user's company specific information about a meter such as Division or Field Technician. All fields listed are custom definable, meaning the labels are user-defined and the edit fields can be converted to drop-downs with a defined list of options.

Custom field labels and drop-down options are managed from the Custom Fields screen within the Settings Manager and requires the FLOWCAL Options privilege.
