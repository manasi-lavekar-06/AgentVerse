## Data Menu

Menu items under the Data menu are available when in edit mode.

The following items are available on the Data Menu in the Calculated Meter Editor:

- **Refresh** - Reload the meter from the database
- **Find** - Open the find tool to search members of a calculated meter
- **Show Avail Meter Char Info** - Adds direction, class, and status columns to the list of available meters or locations. This is optional to avoid performance issues with querying meter characteristics if these columns were to be included by default.
