## Relationship Tab

The relationship tab displays the meters and/or locations that make up the calculated meter for the time frame selected.

Click any column header to sort the data by that column, in ascending or descending order.

- **X** - Multiplier

  This function is available for any member/direction type.

- **System** - System associated with the meter or location

- **L/M** - Indicates whether a member is a location or meter

- **Number** - Meter or location number

- **Name** - Meter or location name

- **Class** - A meter class or "meter purpose" used to provide FLOWCAL categories for grouping meters within viewers and reports (e.g., Sales, Receipt, Delivery).

- **Direction** - Meter or location direction (e.g., Inlet, Outlet). The meter member directions allowed are dependent on the direction of the calculated meter. If the calculated meter has a direction of "Throughput", the meter members must have a direction of "Throughput" as well. If throughput meters are added as members of a calculated meter, the contribution must be specified (positive or negative) before the calculated meter is saved.

- **Type** - Meter or location type (e.g., Orifice, Turbine, Station)
