## Tools Menu

Menu items under the Tools menu are available when in edit mode. The Info menu item is available from both edit and new mode.

The following items are available on the Tools menu in the Calculated Meter Editor:

- **Contact Selection** - Contact Relationships can be designated for meters, sources and locations.

The user can associate specific contacts (email addresses) to a calculated meter. Exceptions and messages logged for the meter will automatically be emailed to the associated contacts for exceptions and messages set up for the contact type.

- **Validations\*** - When a calculated meter is rolled up, if validations are enabled, an exception will be logged if the value comes in outside the range defined.

- **Info** - Contains user-definable fields and an additional notes section.

  The notes stored on the Info screen are only available from the Calculated Meter Editor Info menu. For notes that can be accessed throughout the application (e.g., Volume Editor), right-click on the Calculated Meter Editor screen to add or view notes.

- **Validate Hierarchy\*** - The Validate Hierarchy tool assists users in troubleshooting issues. The user opens the Validate Hierarchy tool from the Calculated Meter Editor, then chooses the validation options to run: Show Invalid Tieover, Show Invalid Transfers, Validate Throughput as Tieover, and Show Unused Meters.

- **Find Parent Locations\*** - The Find Parent Locations tool can be used to find a meter within a large hierarchy, or find all locations that a meter belongs to. From the Calculated Meter Editor Tools menu, select Find Parent Locations and enter part or all of the meter number into the filter. Select the meter number you are looking for from the left pane. The Right pane will show the locations that the meter is a member of.

- **Product Conversion\*** - Not applicable for calculated meters.

\* These values are carried over from the Location Editor and do not apply to calculated meters.
