# <span id="aanchor123"></span> Edit Close Groups

After creating a close group, you can update the close group number or name by editing this data on the Close Groups screen. You can also enable or disable the close group.

<div class="procedure">

To edit a close group:

1.  Go to **Setup** \> **Close Groups**.
2.  Click **Edit**.
3.  Update the close group data as needed.
4.  Click **Save** to apply changes.

</div>

Close groups cannot be deleted.
