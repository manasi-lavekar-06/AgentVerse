## Comparison Location Menu

The following options are available on the Comparison Location menu:

- **New** - Create a new comparison location. The fluid phase will be set to the user-defined default fluid phase configured within [User Preferences](../Settings%20Manager/User%20Settings/User%20Preferences.md). To set the fluid phase manually, click the drop-down on the **New** button and select **Gas** or **Liquid**.

  The gas and liquid fluid phases are only available with the FLOWCAL Gas and Liquid modules, respectively.

- **Edit** - Enable Edit mode.

- **Save** - Save changes.

- **Delete** - Delete the selected location.

- **Cancel** - Cancel edits and do not save changes.

- **Exit** - Exit the screen.
