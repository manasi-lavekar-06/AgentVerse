## Tools Menu

The following items are available on the Tools menu:

- **Info**

> - **Alt ID** - Not used anywhere else, this is an FYI field.
> - **Fluid Phase** - The fluid phase for the location (gas or liquid) determines which columns to initially display in the Meter/Location Rollup Viewer. This is defined on location creation and cannot be changed once the location is created.
> - **Meas. Area** - Select a measurement area from the drop-down or, with System Information privileges, click **New** and create a new measurement area.
> - **Custom Fields** - Labels can be user-defined. (See: [Define Custom Field Labels](../Admin%20Options/Create%20User-Defined%20Fields.md))
> - **Notes** - Open area for storing comments and information about this location.

- **Contact Selection** - Contact relationships can be designated for meters, sources, and locations.

Users can associate specific contacts (email addresses) to a location. Exceptions and messages logged for the location can be configured to trigger an email to the associated contacts.
