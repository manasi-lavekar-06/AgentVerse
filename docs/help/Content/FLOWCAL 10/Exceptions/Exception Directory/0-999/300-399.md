## 300

#### 300 Prove overdue (contractual volume allowed between proves exceeded)

<div class="drop-down" mc-target-name="00300">

This exception is generated on periodic records if the volume accumulated since the prior prove on the meter until the periodic record effective date is greater than the contractual limit. When this validation is enabled, there must be manual prove adjustments for batches. To enable this validation, a contractual limit for Accumulated Vol Between Proves must be configured for the meter on Contractual Limits. The contractual limit configuration must be effective for the date of data being validated. Totalizer Digits in the meter characteristics must be specified.

The accumulated volume for the periodic record since the prior prove on the meter is calculated as (Indicated Volume Start Index for the periodic record - Current Index for the prove). If IV start index is less than the current index, the calculation takes Totalizer Digits into account for index rollover calculations.

For example, liquid meter PROVE_METER has Totalizer Digits of 5. There are 2 batches in August 2017 with effective dates 8/1/2017 7:00:00 and 8/15/2017 7:00:00. There is a contractual limit record for this meter with effective dates 1/1/2017 7:00:00-1/1/2018 7:00:00. On the contractual limit record, the contractual limit for Accumulated Vol Between Proves is set to 8000.

A prove adjustment is made to the 8/1/2017 batch with the prove date of 8/1/2017 09:17:44 and current index of 305. Periodic record at 8/14/2017 17:00:00 has an Indicated Volume Start Index of 8424. The accumulated volume since prior prove for the periodic record is then calculated as 8424 – 305 = 8115. This is greater than the contractual limit of 8000, so exception 209 is generated for the periodic record.

Another prove adjustment is made to the 8/15/2017 batch with the prove date of 8/15/2017 8:44:21 and current index of 2503. Periodic record at 8/28/2017 23:00:00 has an Indicated Volume Start Index of 1229. The current index is smaller than the IV start index, so Totalizer Digits of 5 is used for the accumulated volume calculation which yields 10000 + 1229 - 2503 = 8726. This is greater than the contractual limit of 8000, so exception 209 is generated for the periodic record.
