## 6501 - 6600

<div class="drop-down">

String event and alarm (SEA) exceptions are unique in FLOWCAL in that they have an editor to set the parameters for the generation of each exception. These exceptions have a default severity set to 0. If this exception is being generated, criteria has been created for the exception and the severity level has been raised.

Exceptions  6501 – 6600 have the same functionality as other exceptions in the Exception Description Editor. Users can:

- Modify the description
- Set the severity from 0 (do not generate) to 5
- Assign a contact group to notify when the exception is generated

Users can also click the **Edit Criteria** button to launch the Exception Criteria Editor and configure the criteria required to generate the custom exceptions for string events and alarms.

Multiple events or alarms may be attached to a periodic record that will generate the exception; however, only one record for a given exception number will be generated for any periodic record. For example: A string of low battery may trigger 60 alarms within an hour, but if exception 6501 is set to generate when this occurs, then only one exception 6501 will be generated for the hour.
