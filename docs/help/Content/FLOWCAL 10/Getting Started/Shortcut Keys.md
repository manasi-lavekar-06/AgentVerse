# <span id="aanchor473"></span> Shortcut Keys

The following shortcut key functions are available in FLOWCAL:

| Key | Function | Screen or Field |
|:--:|:---|----|
| F1 | Launch the application help | Main Screen |
| F2 | Open the Volume Editor | Main Screen |
| F3 | Initiate a manual import | Main Screen |
| F5 | Refresh the screen | Data Grids |
| F10 | Log in to or log out of FLOWCAL | Main Screen |
| Alt+F1 | Launch the Settings Manager | Main Screen |
| Alt+S<sup>\*</sup> | Set the start date to start of time | Date Selector (first) |
| Alt+E<sup>\*</sup> | Set the end date to end of time | Date Selector (end) |
| Ctrl+A | Select all rows of data | Data Grids |
| Ctrl+S | Set the start date to start of time | Date Selector (first) |
| Ctrl+E | Set the end date to end of time | Date Selector (end) |
| Ctrl+T<sup>‡</sup> | Switch to TESTit Personality Mode | Main Screen |

\* Exception Resolver only

‡ Available for TESTit 2 Integrated only
