# <span id="aanchor80"></span> Associating TESTit Devices to Contact Types

This functionality is only available with TESTit 2 Integrated.

Some devices in TESTit, such as test reports and calibration devices, may have contact types associated with them. Contact types can be used to assign these devices to a contact or group of contacts.

Two contact types ("Technician" and "Witness") are created by default; more can be added and managed from the [Contact Type Editor](../../Settings%20Manager/Contacts/Contact%20Type%20Editor.md). The Contact Type Editor is used to define these Contact Types for use in the various Contact Selection screens under the device related editors. The contacts set up for each device are notified by email when changes are made to that device and saved.

<div class="procedure">

To set up contacts for test reports:

1.  From the FLOWCAL main menu, go to **Setup** \> **TESTit Manager** \> **Quick View Report**.

2.  All TESTit enabled meters are available in the **Device** drop-down selection list. After selecting the appropriate device, click the **New** button to create a new test report.

3.  In the **Contacts** area of the screen, set the contacts or contact group for each contact type displayed. One or more contacts can be set for each contact type.

    Only the contact types enabled for test reports are available to be set up.

4.  Click the **Save** button.

To set up contacts for calibration devices:

1.  From the FLOWAL main menu, go to **Setup** \> **Calibration Device**.

2.  Go to **View** \> **Contact Relationships**.

3.  In the **Contacts** area of the screen, set the contacts or contact group for each contact type displayed. One or more contacts can be set for each contact type.

    Only the contact types enabled for calibration devices are available to be set up.

4.  Click the **Save** button.

</div>
