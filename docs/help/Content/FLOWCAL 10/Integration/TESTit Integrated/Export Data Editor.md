# <span id="aanchor158"></span> Export Data Editor

This functionality is only available with TESTit 2 integration.

TESTit allows users to export information about meter tests. You can choose to export test report data, meter definitions, list definitions, configuration data, contact data, etc. You can then upload your data to TESTit Enterprise and share your information with other TESTit users.

1.  From the menu bar, choose the **Export** button.

2.  Click the **New** button.

    You can either choose one of the following to export: Device, Lists, Locations, Test Reports, Schedules, Contacts, Configuration data, or export multiple items by selecting more than one of the options.

3.  Click the **Continue** button.

4.  You can set the export name and file name in this window.

    Click **…** to select a directory and file name where you would like to export the data to.

    You can email the export by selecting Email Export and then entering an email address.

    If Email Export is selected, the export will not be saved locally.

    The contact creating the export can also be emailed by selecting **Notify Me On Import**.

    Depending on the type of export option was selected, click **Export Now** or **Email Now**. Once the data is exported, you will see the file located in the directory specified or in the email specified. The file will have a .tsx extension (e.g., testreports.tsx).
