# <span id="aanchor292"></span> Model Type Editor

The Model Type Editor is used to define custom model types. All model types must be of a base type, which can be a: meter, GQ source, transmitter, recorder, or RTU.

This functionality is only available with TESTit 2 integration.

<div class="procedure">

To add a new model type:

1.  From the main **TESTit Integrated** menu, go to **Set-up** \> **Brand/Model**.

2.  Create new model and on the button to the right of the Model Type heading to access the Model Type Editor screen.

    TESTit comes installed with a default model for each type.

3.  Click **New** and enter the new model type (meter, calibration device, recorder, or RTU).

4.  Enter the model type name.

5.  Click **Save**.

Edit existing model types by selecting an existing type and clicking **Edit**.

If necessary, click the **Undo** button to revert changes you have made.

</div>
