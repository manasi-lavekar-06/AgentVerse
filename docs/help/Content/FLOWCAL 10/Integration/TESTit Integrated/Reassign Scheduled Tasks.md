# <span id="aanchor353"></span> Reassign Scheduled Tasks

This functionality is only available with TESTit 2 integration.

Scheduled tasks can be reassigned to different users in TESTit.

<div class="procedure">

To reassign a scheduled task:

1.  Open Schedule Definition Viewer by clicking the Schedule Definition Editor button.
2.  Click the \> to expand the object (meter, lists, etc.) and see the currently scheduled tasks related to the object.
3.  Right-click an object and select **Reassign**.
4.  Select the user to reassign the task to and click **Select**. The task has now been reassigned.

</div>
