# <span id="aanchor145"></span> Schedule Frequency Editor

This functionality is only available with TESTit 2 integration.

The Scheduling Frequency Editor is used to define frequencies that are used in the schedule definitions.

<div class="procedure">

To add a new schedule frequency:

1.  Click the **Schedule Definition Editor** button.
2.  Click the **New** button.
3.  From the Schedule Definition Editor window and after setting up the device information to be Recurring, click the button to the right of the **Frequency** drop-down list to open the Schedule Frequency Editor.
4.  Click **New**.
5.  Enter the frequency name.
6.  Enter the value for the number of days, weeks, or months.
7.  Select the unit type from the drop-down list.
8.  Click **Save**.

</div>
