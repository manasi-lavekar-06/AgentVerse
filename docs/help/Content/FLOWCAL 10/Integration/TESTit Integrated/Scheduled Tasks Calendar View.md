# <span id="aanchor25"></span> Scheduled Tasks Calendar View

This functionality is only available with TESTit 2 Integrated.

The Calendar View shows the scheduled tasks on a calendar much like Microsoft Outlook. From this view you can easily see tasks for the selected day, week, month, or year.

<div class="procedure">

To access the calendar view:

1.  From View \> Schedules View or by clicking on the quick access toolbar icon\[Schedules button.PNG\].
2.  The calendar view uses different colors to represent the state of the different tasks.
    - **White** – The task is not yet due
    - **Yellow** – The task is due
    - **Red** – The task is over due
    - **Green** – The task has been completed
    - **Gray** – Tasks that have been canceled
    - **Turquoise** – Represents reoccurring entries
3.  The view can be easily filtered to show all tasks or any combination of scheduled, due, overdue, completed, and canceled. The tasks can also be filtered for all users or a specific user.
4.  Scheduled items can be moved around the calendar (within their grace period) simply by clicking and dragging an item from one day to another.
5.  The task can be performed by double-clicking on the scheduled item. New tasks can be added by double-clicking a day on the calendar.
6.  Schedule entries can be exported to Microsoft Outlook, Microsoft Excel, Plain Text, HTML, and XML.
7.  To export click File \> Export Calendar and click on the format to export the schedule to.

</div>
