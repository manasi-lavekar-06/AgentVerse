# <span id="aanchor358"></span> Scheduled Tasks Grid View

This functionality is only available with TESTit 2 Integrated.

The Grid View shows the scheduled tasks in a grid with powerful filters and sorting options. From this view you can easily find information about scheduled tasks.

<div class="procedure">

To access the grid view:

1.  To access the Grid view, in the Schedules window, select the Grid option under the Views section in the left side of the window.
2.  The view can be easily filtered to show all tasks or any combination of scheduled, due, overdue, completed, and canceled tasks.
3.  The tasks can also be filtered for all users or a specific user. Filtering can also be done on the Device Name, Device Task Name, and Description. The tasks can be sorted quickly by Status, Duration, Scheduled Date/Time, Due Date/Time, and Completion Date/Time.
4.  The task can be performed by selecting a task and clicking Edit.
5.  New tasks can be added by clicking New.

</div>
