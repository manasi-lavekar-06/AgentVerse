# <span id="aanchor26"></span> TESTit Analysis Viewer

The analyses brought over from FLOWCAL to TESTit can be viewed by navigating to the Analysis Viewer while in TESTit personality. Users may also manually input analyses for meters from this viewer. Both analyses originating from FLOWCAL and manually entered analyses can be edited and deleted in the Analysis viewer.

This functionality is only available with TESTit 2 integration (Version 2.14.2 and later).

<div class="procedure">

To access the TESTit Analysis Viewer:

1.  From the main **TESTit Integrated** menu, go to **Set-up** \> **Meter**.
2.  Select the **Analysis** option.

The FcSrvTestITAnalysisSync service must be installed for this functionality to be available.

</div>
