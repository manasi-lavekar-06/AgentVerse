# <span id="aanchor422"></span> Calibration Device Editor

This functionality is only available with TESTit 2 integration.

The Calibration Devices Editor is used to create calibration devices in TESTit.

<div class="procedure">

To access the Calibration Device Editor and create a new device:

1.  From the main **TESTit Integrated** menu, go to **Set-Up** \> **Calibration Device**.
2.  Click **New**.
3.  Select the type of calibration device (Temperature, Static Pressure, Differential Pressure, Static Differential Pressure Combo, Test Measure, Gravity, Electronic Device, or Mechanical Device). 
4.  Enter the model name, manufacturer, and serial number. If the calibration device type is "Static Pressure" or "Static Differential Pressure Combo", you will need to select a pressure unit.
5.  Confirm whether the calibration device is a current active calibration device. 
6.  Click **Save**.
7.  Upon saving, you will be prompted to set up schedule definitions for the new device. If you click **Yes**, the Schedule Definition Editor screen will appear.

To edit an existing calibration device:

1.  Select the device and click **Edit**.
2.  While editing, you can configure all aspects of the calibration device, including the option to add or edit schedule definitions. Click **Add/Edit Schedule Definitions** to access the Schedule Definition Editor.
3.  If necessary, click the **Undo** button to revert changes you have made.

</div>
