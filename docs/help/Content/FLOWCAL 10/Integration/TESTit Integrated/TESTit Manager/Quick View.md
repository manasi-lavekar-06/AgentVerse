# <span id="aanchor220"></span> Quick View

This functionality is only available with TESTit 2 integration.

The Quick View allows users to quickly select a single device, Meter, GQ Source, Calibration Device, Prover, or Miscellaneous Device, and view all completed tested associated with the device. By only displaying one device at a time it allows the user to focus only on the selected meter and better control over which data is displayed. The quick view gives the user the ability to filter by the completed task name and date range.

<div class="procedure">

To access the Quick View screen:

Go to **Test Reports** \> **Create/View Test Reports** \> **Quick View**, or click the quick view button on the quick access toolbar.

</div>
