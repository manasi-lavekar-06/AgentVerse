# <span id="aanchor499"></span> Tree View

This functionality is only available with TESTit 2 integration.

The Tree View allows users to see all of the available devices, Meters, GQ Sources, Calibration Devices, Provers, Miscellaneous Devices, Lists, and Locations, in hierarchical view. Each device in the tree view can be expanded to reveal any completed tests, if any exists, and collapsed again to hide the revealed tests.

Since the tree view has the ability to display large amounts of data at one time TESTit provides the user with different order and filter methods that can be used to make specific data easier to find.

Lists, Locations, Meters, and GQ Sources can all be ordered by number or name. Calibration Devices and Provers can be ordered by type, model, or manufacturer. Tests can also be filtered by a date range. Only tests that fall into the specified date range are displayed making it even easier to find the test the user is looking for.

<div class="procedure">

To access the Tree View:

Go to **Test Reports** \> **Create/View Test Reports** \> **Tree View**, or click the tree view button on the quick access toolbar.

</div>
