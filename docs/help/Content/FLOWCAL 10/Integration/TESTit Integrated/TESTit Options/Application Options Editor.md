# <span id="aanchor461"></span> Application Options Editor

This functionality is only available with TESTit 2 integration.

The Application Options Editor is used to configure different system options, including whether to display the flow/total flow rate error, plate size tolerance, com device setup, and configuration of test points.

<div class="procedure">

To access the Application Options Editor:

From the main **TESTit Integrated** menu, go to **Application** \> **Application Options**.

</div>
