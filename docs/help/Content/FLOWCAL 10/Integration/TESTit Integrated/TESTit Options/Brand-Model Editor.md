# <span id="aanchor166"></span> Brands & Models Editor

The Brands & Models Editor is used to set up brands and models of equipment used by your company. The interface has a hierarchical view. You can expand a particular brand to see associated models.

This functionality is only available with TESTit 2 integration.

<div class="procedure">

To add a new brand:

1.  From the main **TESTit Integrated** menu, go to **Set-up** \> **Brand/Model**.
2.  Click **New** and select **Add New Brand**.
3.  Enter a brand name.
4.  Click **Save**.

To add a new model:

1.  Click **New** and select **Add New Model**.
2.  Select a model type such as a GQ source, meter, RTU, recorder, static pressure transmitter, differential transmitter, or temperature transmitter.
3.  Enter a model name.
4.  Click **Save**.

Edit existing brands and models by selecting an existing brand or model and clicking **Edit**.

If necessary, click the **Undo** button to revert changes you have made.

</div>
