# <span id="aanchor508"></span> Custom Tab Editor

The Custom Tab editor allows administrators to create custom tabs that can be configured and used in test reports to display additional information.

This functionality is only available with TESTit 2 integration.

<div class="procedure">

To create a custom tab:

1.  From the main TESTit Integrated menu, go to **Administrator** \> **Custom Tab**.
2.  Click **New**.
3.  Enter a tab name.
4.  Select a tab type.
5.  Click **Save**.

To edit a custom tab:

1.  Select a custom tab and click the **Edit** button.
2.  Edit the tab name and type as needed.
3.  If necessary, click the **Undo** button to revert changes you have made.

</div>
