# <span id="aanchor318"></span> Custom Task Editor

This functionality is only available with TESTit 2 integration.

The Custom Task Editor allows administrators to create custom tasks that they can configure and use in test reports for additional information that they might require their meter technicians to retrieve.

<div class="procedure">

To create a custom task:

1.  From the main TESTit Integrated menu, go to **Administrator** \> **Custom Task**.
2.  You can view all current device tasks and the tabs associated with them by selecting them from the device task name drop-down lists. The available tabs are located on the left and the tabs associated with the task are on the right.
3.  Click the **New** button.
4.  Enter a task name and description.
5.  Select a task type:
    - **Meter Test Report** – Only Meters will be able to have this task preformed on them.
    - **GQ Source Test Report** – Only GQ Sources will be able to have this task preformed on them.
    - **Calibration Device Test Report** – Only Calibration Devices will be able to have this task preformed on them.
    - **Miscellaneous Event** – Task for Miscellaneous events.
    - **DISABLED** – Use this option to disable a task from being used.
6.  Select the type of report that you would like to be associated with this task.
7.  Add tabs to the task by selecting the task and clicking the add arrow.
8.  You can also remove tabs by clicking the remove arrow.
9.  Custom tabs that you created will also be available for you to add to the tasks.
10. Click **Save**.
11. To edit a custom task, select the custom task you wish to edit and click **Edit**.
12. You can edit the task name, task description, task type, task report file, and the tabs that are associated with the task.
13. To undo changes you have made while in edit mode click **Undo**.

You can now use these custom or updated tasks for test reports. If you edited a standard test report the changes will cascade to all of the existing test using that test report so you will not have to reschedule any tasks.

</div>
