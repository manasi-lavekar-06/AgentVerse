# <span id="aanchor238"></span> Drop-Down List Setup

This functionality is only available with TESTit 2 integration.

Setting a field to be a drop-down list helps control data is that entered in that certain field. Drop-down lists can be created from the Drop-Down List Editor.

<div class="procedure">

To change a field to a drop-down list:

1.  Select the field you want to change.
2.  Hover over **Form Configuration** on the right side of the screen and check the **Drop-Down List** check box.
3.  After the field has been changed to a drop-down list, the administrator can select the drop-down list type that will be used. All of the lists that have been created in the Drop-Down List editor will appear as options.
4.  The field has been successfully changed to a drop-down style list. To remove this setting, right-click and deselect the drop-down option.

</div>
