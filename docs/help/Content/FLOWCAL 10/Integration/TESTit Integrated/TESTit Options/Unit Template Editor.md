# <span id="aanchor193"></span> Unit Template Editor

This functionality is only available with TESTit 2 integration.

The Unit Template Editor allows you to create templates to use for unit conversion for various factors affecting the calculations. For convenience you can click either the All “Units to US” or “All Units to Metric” buttons to quickly change all of the units at once.

<div class="procedure">

To create a unit template:

1.  From the main **TESTit Integrated** menu, go to **Test Reports** \> **Unit Template**.
2.  Click **New**.
3.  Enter the template name and units to be used with each of the items listed.
4.  Click **Save**.

</div>
