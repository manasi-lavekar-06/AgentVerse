# <span id="aanchor399"></span> Schedule Definition Editor

This functionality is only available with TESTit 2 integration.

The Schedule Definition Editor is used to set up schedules for tasks to be performed.

<div class="procedure">

To access the Schedule Definition Editor:

1.  Open Schedule Definition Editor by clicking the Schedule Definition Editor button. Then click New.

2.  Next to the Device field, click the Device tree view button to select the device to schedule from the tree view.

    The option to create schedule definitions was chosen after creating a device such as a meter or GHQ source. When then New button is clicked the device that is currently being created will be populated in the device field.

3.  Select the Device Task to schedule.

4.  Select the person to whom this will be Assigned To.

5.  Enter the Grace Period, or number of days after the tests due date a user has to complete the test.

6.  Check whether this task will be Recurring. If so, select the Frequency.

    If the frequency you would like to use it not available you can open the [Schedule Frequency Editor](../Schedule%20Frequency%20Editor.md) by clicking the ellipses.

7.  Select the Next Due Date.

8.  Click Save.

9.  The scheduled definition will now be added to the Calendar and Grid View the next time the Scheduler Service runs.

</div>
