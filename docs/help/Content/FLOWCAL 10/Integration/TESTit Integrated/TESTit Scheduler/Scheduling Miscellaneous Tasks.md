# <span id="aanchor521"></span> Scheduling Miscellaneous Tasks

This functionality is only available with TESTit 2 Integrated.

Miscellaneous tasks cannot be scheduled until a custom task had been created to be used with the miscellaneous tasks.

1.  Add a link to custom task + tab creation.
2.  Miscellaneous Task can be scheduled form the [Schedule Definition Editor](Schedule%20Definition%20Editor.md).
3.  These tasks will be viewable from both the grid view and calendar view.
