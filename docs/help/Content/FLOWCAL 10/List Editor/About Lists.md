# <span id="aanchor432"></span> About Lists

FLOWCAL lists are logical groupings of locations, meters or sources, used for generating reports and exports, importing data, and viewing data.

Three types of lists are available in FLOWCAL:

- **Static** - A static list only changes if you access the list through the List Editor, click the **Edit** button, and modify the list members.
- **Dynamic** - A dynamic list is based on a user-defined query created in the [Query Editor](../Tools/Query%20Editor.md). This list changes based on returns from the associated query.
- **Ordered** - An ordered list contains members listed in the order in which they were added. Typically, ordered lists are used for printing chart labels for gas meters in the order that the technician pulls the charts.

By default, static and dynamic lists are sorted by object number (i.e., meter, location or source number).
