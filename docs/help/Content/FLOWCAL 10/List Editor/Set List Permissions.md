# <span id="aanchor497"></span> Set List Permissions

Provide certain groups and users access to the list using the Group and User Access tab. By default, the user creating the list will have access. Any other groups or users must be added if they are to have access.

While in Edit mode, use the arrow buttons to set access for specific users and groups, or use the **Select All** and **Reject All** buttons to grant or restrict access to the list for all users or groups.

Only users or groups with the **List View** privilege can be assigned to a list.
