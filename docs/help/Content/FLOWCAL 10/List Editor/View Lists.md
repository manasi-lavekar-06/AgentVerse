# <span id="aanchor122"></span> View Lists

You can view the members of a list from the List Editor.

<div class="procedure">

To view lists:

1.  Go to **Setup** \> **List** to open the List Editor.
2.  Click the **List** button and select "List" or "Source List".
3.  The members of the list will display under the Selected grid. For meter and/or location lists, you can elect to see locations only, meters only, or both.
4.  The user to last modify the list, and the date of the last change, are displayed at the bottom of the screen.

</div>

You can also use the List Editor to find members in a large list or to find other lists that a given member belongs to.

- **Tools \> Reverse Lookup** - Select a list member to see the lists the member belongs to. Select a list and click **Delete** to remove the member from the selected list.
- **Search \> Find** - Launches a text box to allow you to quickly search through the grid. You can also press **Ctrl+F** or right-click the grid and select **Find**.

#### List Notes

Select a list in the List Editor and right-click the top half of screen to view or add notes associated with the list.
