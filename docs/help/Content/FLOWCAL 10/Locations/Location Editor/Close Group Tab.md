## Close Group Tab

Once a meter or group of meters have been assigned to a location, the user can assign that location to a close group. The Close Group tab allows the user to assign a location to more than one close group during different time periods. Close groups can also be assigned in bulk from the Bulk Changes screen.

Locations can be assigned to close groups. The Close Group tab was added to the Location Editor for liquids to close tickets associated to the location. For gas, if the user associates a location to a close group and closes it, all the meters within the location will be closed automatically.
