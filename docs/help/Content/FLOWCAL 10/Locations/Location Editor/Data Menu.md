## Data Menu

 These menu options are only enabled when the Location Editor is in Edit mode.

The following options are available on the Data menu in the Location Editor:

- **Refresh** - Reload the meter from the database
- **Find** - Open the find tool to search members of a calculated meter
- **Show Avail Meter Char Info -** Add direction, class, and status columns to the list of available meters or locations (optional). This option can help reduce performance issues when querying meter characteristics if these columns were to be included by default.
