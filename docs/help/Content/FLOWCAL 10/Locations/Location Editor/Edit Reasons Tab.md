## Edit Reasons Tab

FLOWCAL can be configured to require an edit reason when editing a location. By default, this feature is disabled. To enable it, select the location type to enable on the System Configuration screen. Once enabled, an edit reason is required before saving edits to a location. Edit reasons are filtered according to the date range selected for the location.

- **Effective Date** - The datetime to which the edit reason applies
- **Comment** - The edit/comment entered during a location edit
- **Username** - The username of the user that made the edit
- **GMS Date** - The datetime at which the edit was applied
