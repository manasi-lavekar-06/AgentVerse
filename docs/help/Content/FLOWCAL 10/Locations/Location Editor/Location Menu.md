## Location Menu

The following options are available on the Location menu in the Location Editor:

- **New** - Create a new location.

  A fluid phase of liquid is only available with the **FLOWCAL Liquids** module.

- **Edit** - Enable edit mode.

- **Save** - Save changes to data.

- **Cancel** - Cancel edits and do not save.

- **Delete** - Delete the selected location

- **Security** - View or edit users that have access to the location.

  User/group access to calculated meters is only relevant for companies that maintain object-level security. Most companies do not restrict access at the object level.

- **Exit** - Exit the Location Editor screen.
