## Members Tab

The Members tab displays the meters and/or locations that make up the location for the time frame selected. All the meters and locations that are members of a location are totaled to the parent location during rollups.

Click any column header to sort in ascending or descending order.

The following items are available on the Members tab:

- **X** - Multiplier.

  This value cannot be edited for members that have a direction of "Tieover" or "Transfer".

- **System** - System that the meter or location is associated with.

- **L/M** - Indicates whether a member is a location or meter.

- **Number** - Meter or location number.

- **Name** - Meter or location name.

- **Class** - A meter class or "meter purpose" used to provide FLOWCAL categories for grouping meters within viewers and reports (e.g., Sales, Receipt, Delivery).

- **Direction** - Meter or location direction (e.g., Inlet, Outlet).

- **Type** - Meter or location type (e.g., Orifice, Turbine, Station).
