# <span id="aanchor8"></span> View Location Data

All meters and locations under a parent location are rolled up to the parent location (i.e., everything totals upward in a tree). Several viewers display this rollup data, including the Meter/Location Rollups, Daily, Monthly, and NGL Balance Viewers.

<div class="procedure">

To access the rollup viewers:

Go to **Open** \> **Rollup Viewers**.
