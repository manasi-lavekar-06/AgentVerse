# <span id="aanchor169"></span> Edit Meter Data

Once a meter has been created in FLOWCAL, you can make edits to the meter information or other meter data, such as the flow data.

#### General Information

General meter information, such as custom fields, validations and import options, can be edited from the Meter Editor.

You can make the same edit across several meters from the Bulk Changes screen.

<div class="procedure">

To edit a meter from the Meter Editor:

1.  Open the Meter Editor, and select a meter using the Meter drop-down.
2.  Click the **Edit** button or go to **Meter** \> **Edit** from the Meter Editor menu.
3.  Populate required fields (highlighted in green). These fields must be populated before you can save your changes.

By default, Fluid Phase is a required field; however, additional fields may be required based on how FLOWCAL options are configured.

1.  Enter any additional meter information and click **Save**.

    If you change the meter number, FLOWCAL will prompt you to confirm the change before proceeding.

</div>

#### Flow Data

Flow data, meter characteristics, and meter analysis can be viewed and edited from the Volume Editor. You can also use the Volume Editor to manually enter data. This data is rolled up into hourly, daily and monthly records, which are then available in the Meter/Location Rollup Viewer. This rolled data is primarily used for reporting externally and internally to other departments and downstream systems.
