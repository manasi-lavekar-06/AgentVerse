# <span id="aanchor356"></span> Date and Time Adjustments During Import

FLOWCAL’s standard import drivers can apply three types of adjustments to datetimes contained in meter and ticket data import files:

- Convert time trails data to time leads prior to import
- Adjust for Daylight Saving Time prior to import
- Adjust by the offset defined for the meter or location time zone prior to import

<div class="drop-down" style="display: none;" mc-target-name="TTTL">

When Time Leads Shift is enabled, meter import records with time trails data spans are converted to and then imported as time leads records.

- The Time Leads Shift option applies only to gas meters.
  - As liquid meters can only have record span of Time Leads in FLOWCAL, TT→TL conversion upon import happens for liquid meters when needed regardless of any option.
  - Ticket data is not designated as time trails or leads; therefore, this adjustment is not applicable to ticket data.
- Among data points that represent datetime, TT→TL adjustments are applicable only to those data points that represent a span of time, not a point in time.
- In a CFX file, two Meter Configuration section fields are used to determine whether to do a TT→TL adjustment.
  - If the Time Span value is T (time trails), timestamps of History records are adjusted.
  - If the Alternate Time Span value is T (time trails), timestamps of Alternate Periodic Values records are adjusted.

The following factors are considered when calculating the effective date of the converted time leads record (not in order):

- Beginning of the periodic defined by record resolution, contract day, and contract hour
- Duration, if specified for the import record
- End effective date of preceding record in the current import file
- Start and end effective dates of any existing data in the same periodic

</div>

<img src="data:image/gif;base64,R0lGODlhEAAQAPcAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAACH5BAEAAP8ALAAAAAAQABAAAAgdAP8JHEiwoMGDCBMqXMiwocOHECNKnEixosWBAQEAOw==" class="MCToggler_Image_Icon" data-mc-alt2="Open" width="16" height="11" alt="Closed" />Daylight Savings Time (DST) Adjustment</a>

<div class="drop-down" style="display: none;" mc-target-name="DST">

When the DST shift is enabled, all dates and times that occur during Daylight Saving Time will be shifted forward an hour. All time stamps outside of DST will be imported as-is.

### Standard Time to Daylight Saving Time (Spring Forward) Adjustment

If import records are time trails, import records with timestamps of 2:00:00 AM or earlier of the start date of DST are imported as-is. The import records with timestamps later than 2:00:00 AM of the start date of DST are imported with one hour added.

| In Import File (Before Shift) | In Database (After Shift) |
|-------------------------------|---------------------------|
| 3/14/2021 1:30:00             | 3/14/2021 1:30:00         |
| 3/14/2021 1:59:59             | 3/14/2021 1:59:59         |
| 3/14/2021 2:00:00             | 3/14/2021 2:00:00         |
| 3/14/2021 2:00:01             | 3/14/2021 3:00:01         |
| 3/14/2021 2:30:00             | 3/14/2021 3:30:00         |
| 3/14/2021 3:00:00             | 3/14/2021 4:00:00         |

If import records are time leads, import records with timestamps earlier than 2:00:00 AM of the start date of DST are imported as is. The import records with timestamps of 2:00:00 AM or later of the start date of DST are imported with one hour added.

| In Import File (Before Shift) | In Database (After Shift) |
|-------------------------------|---------------------------|
| 3/14/2021 1:30:00             | 3/14/2021 1:30:00         |
| 3/14/2021 1:59:59             | 3/14/2021 1:59:59         |
| 3/14/2021 2:00:00             | 3/14/2021 3:00:00         |
| 3/14/2021 2:00:01             | 3/14/2021 3:00:01         |
| 3/14/2021 2:30:00             | 3/14/2021 3:30:00         |
| 3/14/2021 3:00:00             | 3/14/2021 4:00:00         |

### Daylight Saving Time to Standard Time (Fall Back) Adjustment

This adjustment will continue until 1:00:00 AM on the end date of DST.

If import records are time trails, the import records with timestamps later 1:00:00 AM on the end date of DST are imported as-is.

| In Import File (Before Shift) | In Database (After Shift) |
|-------------------------------|---------------------------|
| 11/7/21 0:30:00               | 11/7/21 1:30:00           |
| 11/7/21 0:59:59               | 11/7/21 1:59:59           |
| 11/7/21 1:00:00               | **11/7/21 2:00:00**       |
| 11/7/21 1:00:01               | 11/7/21 1:00:01           |
| 11/7/21 2:00:00               | 11/7/21 2:00:00           |

If the import records are time leads, the import records are imported as-is, starting with 1:00:00 AM on the end date of DST.

| In Import File (Before Shift) | In Database (After Shift) |
|-------------------------------|---------------------------|
| 11/7/21 0:30:00               | 11/7/21 1:30:00           |
| 11/7/21 0:59:59               | 11/7/21 1:59:59           |
| 11/7/21 1:00:00               | 11/7/21 1:00:00           |
| 11/7/21 1:00:01               | 11/7/21 1:00:01           |
| 11/7/21 2:00:00               | 11/7/21 2:00:00           |

</div>

When Time Zone Shift is enabled, all dates and times will be adjusted by the offset amount defined for the selected time zone. For example, if Central Standard Time (CST) has an offset of +1, a CFX record with a date and time of 1/1/2017 12:00:00 will be imported into a meter in the CST time zone as 1/1/2017 13:00:00.

</div>

To enable these options, set each item to "Yes". These options are disabled by default.

- **Meter Data** - For meter data, the options can be enabled at the meter level through the Meter Editor Imports tab.
- **Ticket Data** - For ticket data, the options can be enabled at the location level (tank, cavern, or location) through the corresponding editor for the tickets belonging directly to the locations to be adjusted and imported.

1.  BTZ
2.  DST
3.  TT→TL
