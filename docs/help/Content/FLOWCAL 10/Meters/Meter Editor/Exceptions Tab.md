#### Exceptions Tab

This tab is not available for dead oil meters or flash gas meters.

On this tab, you can control the severity settings of designated flowing parameter validations. You can also disable an exception by setting the severity to zero.

These severity settings override the application settings defined in the [Exception Description Editor](../../Settings%20Manager/Application/Exception%20Description%20Editor.md).

The Exception Number and Description fields are read-only; these values must be managed from the Exception Description Editor.

Meter message 313 "Exception severity changed" is generated when a severity is changed on this tab. If a contact type is set at the application level, that setting is reflected in the Contact Type column.
