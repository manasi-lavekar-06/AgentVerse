#### Tools Menu

##### Contact Selection

Assign contact name(s) to a contact type for the selected meter that can be configured to receive emails when exceptions or messages are generated for the meter. (See: [Contact Manager](../../Settings%20Manager/Contacts/Contact%20Manager.md) and [Contact Type Editor](../../Settings%20Manager/Contacts/Contact%20Type%20Editor.md))

##### Manage Close Groups

If a close group is assigned for the meter, user can adjust the close group assignment throughout the time in the Close Groups editor, assigning different close group for different dates.

##### HC Properties

Launch the [Hydrocarbon Property Time Frame Editor](../../Source%20Analysis/Hydrocarbon%20Properties/Hydrocarbon%20Property%20Time%20Frame%20Editor.md).

##### Reverse Lookup

Select a meter, source or location list member to see the lists the member belongs to. Select a list and click Delete to remove the member from the selected list.

##### Live Oil Info

Launch the [Live Oil Management](Live%20Oil%20Info.md) form.
