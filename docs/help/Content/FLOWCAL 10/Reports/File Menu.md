## File Menu

The following options are available on the File menu on the Standard Reports screen:

- **Export** - Open the Choose an Export File Directory screen to specify a network path, file format, and other output options. (See: [Export a Report](Export%20a%20Report.md))
- **Email** - Open the Email Reports screen to configure email options. (See: [Email a Report](Email%20a%20Report.md))
- **Print Preview** - Open the Report Viewer with the results of your report selections. If you have selected multiple reports, each report will appear on a separate tab. You can also export or print a report from the Report Viewer.
- **Print** - Open the Print screen to select a printer and print options.
- **Store** - Open the Stored Reports screen. (See: [Stored Reports](Stored%20Reports.md))
- **Exit** - Close the Standard Reports screen.
