# <span id="aanchor435"></span> Report Access

Use the Report Access screen to grant access permissions to specified users or a designated group of users for individual reports or report categories.

If TESTit 3 Integrated is enabled, the TESTit category and reports will not display; these items will only be available from the TESTit application.

<div class="procedure">

To grant/restrict access to reports:

1.  Go to **Report** \> **Access** on the Standard Reports menu or right-click a report or category.
2.  Select **Reports** or **Categories** to show the applicable list of objects.
3.  Select the report or category and click **Edit**.
4.  Select a scope:
    - **Public** – All users have access.
    - **Admin Only** – Users with **Report Scheduler** privileges have access.
    - **Customize** – A specified combination of users/groups have access.
5.  Click **Save**.

</div>
