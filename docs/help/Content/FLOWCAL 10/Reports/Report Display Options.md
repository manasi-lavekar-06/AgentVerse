# <span id="aanchor82"></span> Report Display Options

## Displaying Company and Customer Identification Data on Standard Reports

Depending on user settings, a company logo, customer name, or company name will display in the top right corner of each FLOWCAL standard report. These elements will display in the following precedence:

- If a valid logo image path is provided in the [Rollup Configuration settings](../Settings%20Manager/System/Rollup%20Configuration.md), the logo image displays; or
- For meter-level reports, if the **Print Customer Name** option on the [Meter Editor Reports tab](../Meters/Meter%20Editor/Reports%20Tab.md) is set to **Yes**, the customer specified for the meter on the [Meter Editor General](../Meters/Meter%20Editor/General%20Tab.md) tab displays; or
- The company name specified in the [System Factors settings](../Settings%20Manager/System/System%20Factors.md) for the selected system in the report run displays.
