## Report Menu

The following options are available on the Report menu on the Standard Reports screen:

- **Add** - Open the Available Reports screen to install custom reports found in the **Crystal\Custom** directory of the FLOWCAL installation folder.
- **Refresh** - Refresh the list of categories/reports.
- **Print Orientation** - This feature is no longer supported and will be removed in a later release.
- **Groups** - Open the Report and Export Group Editor to edit, delete, or create report or export groups. (See: [Report/Export Groups](Report%20Scheduler/Report-Export%20Groups.md))
- **Category** - Open the Report Categories screen to edit, delete, or create report categories. (See: [Report Categories](Report%20Categories.md))
- **Access** - Open the Report Access screen to grant/restrict access to reports or categories. (See: [Report Access](Report%20Access.md))
- **Stored Reports** - Open the Stored Reports screen. (See: [Stored Reports](Stored%20Reports.md))
