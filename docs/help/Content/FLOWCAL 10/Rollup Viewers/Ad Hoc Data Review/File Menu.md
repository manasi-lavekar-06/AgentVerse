## File Menu

The following options are available on the Ad Hoc Data Viewer File menu:

- **Refresh** – Refresh data on the screen (this functionality is the same as the Refresh button).

- **Export** – Export all data displayed on the grid to an XLS or CSV file.

  Export file includes object number, object name, date and all data points, and column headers. Data that has been hidden is not included.

- **Find** – Show or hide the Find tool at the bottom of the grid.

- **Exit** – Close the Ad Hoc Data Review screen and return to the main FLOWCAL screen.
