## Options Menu

The following options are available on the Ad Hoc Data Viewer Options menu:

- **Flow Duration** – Specify whether to view the flow time in hh:mm:ss format or as a percentage of an hour.
- **Decimals** – Specify the number of decimals displayed for volume and energy (0–4)
- **Pressure** – Specify whether to display the pressure as absolute, gauge, or the field measurement condition.
- **Options** – Specify the number of data rows to display ("Unlimited" is specified by default). This option allows users to set a value other than "Unlimited" when a large data set is returned, usually involving tens of thousands of meters, which can cause the application to run out of memory when attempting to display the data.
