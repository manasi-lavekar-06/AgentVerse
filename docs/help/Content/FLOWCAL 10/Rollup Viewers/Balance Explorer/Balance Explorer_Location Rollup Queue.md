## Location Rollup Queue

This panel displays whether the selected location is rolled up for all of time. Click the **Refresh** button within the panel to search for non-rolled data under that location for all of time.

- If unrolled data is identified, the following message will display: "There is unrolled data for \<Location\>".
- If no unrolled data is identified, the following message will display: "All data is rolled for \<Location\>".
