## Templates

The Balance Explorer includes four default templates:

- Gas Default View
- Liquid Default View
- NGL View
- Recovery Analysis View

Default templates cannot be modified or deleted.

##### Custom Templates

Users can also create custom templates with preferred variables and location. Custom templates are saved on a per-user basis; users can only access their own custom templates.

<div class="procedure">

To create a custom template:

1.  Select desired locations and variables in the L&U Viewer and Member Viewer variable selectors.
2.  Go to **Templates** \> **Save Current View as a Template**.
3.  Enter a template name (optional).

To manage custom templates, go to **Templates** \> **Manage Templates**. The Manage Templates screen contains all default and custom templates, associated locations (custom templates only), and variable selections. From this screen, you can:

- Update the location and variables as needed.
- Rename a custom template.
- Delete a custom template.

You cannot edit fields for a template in the Manage Templates screen.

</div>
