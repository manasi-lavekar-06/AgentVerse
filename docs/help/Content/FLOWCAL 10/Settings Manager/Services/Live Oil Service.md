# <span id="aanchor29"></span> Live Oil Service

This feature requires the **Liquids System** and **Live Oil Management add-on**.

Periodic data is transferred from live oil to dead oil and flash gas meters using the installed Live Oil service (FlowCal.LiveOil.Service.exe).

## Installation

<div class="procedure">

To install the Live Oil service:

1.  Make sure you have the appropriate permissions required to install services on the applicable server.
2.  Go to the **\FlowCal.LiveOil.Service** directory within the FLOWCAL installation folder.
3.  Right-click the **\_install_Service.bat** file and select **Run as Administrator**.
