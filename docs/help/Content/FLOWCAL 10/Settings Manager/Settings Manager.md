# <span id="aanchor76"></span> Settings Manager

The Settings Manager contains links to configuration options throughout the application. Items are organized by category and include brief descriptions of what the options pertain to.

| Category | Contents |
|:--:|:---|
| User Settings | Login credentials, system preferences, quick launch items, dashboard items |
| Services | Service settings and rollup and transaction queue monitoring |
| Security | User names, contact info, user privileges, and user and group access |
| System | Units of measure, constants, and data parameters |
| Contacts | Contact and company information, and distribution lists |
| Application | Application settings associated with data management, meters, imports, fields, and validations |
| Geographic | Specific information related to geographic areas |
| Calculators | CALCit calculators and unit conversion |
| Liquids | Functions and logistical information specific to liquids data |
| Information | FLOWCAL version number, license usage, database metrics, and customer support information |
