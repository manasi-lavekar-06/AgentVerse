# <span id="aanchor43"></span> System Configuration

Accessing this screen requires **System Information - Can View** permissions.

FLOWCAL ships with a single system called ENTERPRISE. If the Multi-System Extension add-on has been purchased, additional systems can be created.

An example of systems may be different drilling basins. You may only need access to the information for certain drilling basins, not all basins. Additionally, it can be desirable to have liquids in one system and gas in a different system. Options for each system can be configured individually.

While an administrator will set these fields during implementation, analysts benefit from understanding the options by knowing what functionality is available that may or may not have been incorporated in the setup.
