## Tools Menu

The following options are available on the Gas Quality Source Editor Tools menu:

- **HC Properties** - Launch the [Hydrocarbon Property Timeframe Editor](../Hydrocarbon%20Properties/Hydrocarbon%20Property%20Time%20Frame%20Editor.md).

- **User Access** - Display users and groups with access to the selected source.

  User/group access to sources is only relevant for companies that maintain object-level security. Most companies do not restrict access on a per-source basis.

- **Test Reports** - When the TESTit Enable field is set to Yes on the Main tab of the Gas Quality Source Editor, test reports for the selected source can be viewed by selecting the Test Reports menu.

  TESTit v2 Integrated only.

- **Notes** - These notes are associated to the selected gas quality source and can be edited while in Edit mode.

  The notes stored here are only available from the Gas Quality Source Editor. Right-click the top of the Source Quality Source Editor screen to add or view notes that can be accessed throughout the application (e.g., from the Source Analysis Rollup Viewer).

- **Contact Selection** - See: [Create Contact Types](../../Admin%20Options/Create%20Contact%20Types.md)

- **GQ-GQ Association** - The GQ-GQ Association menu is only available when in new mode. This feature is used to reduce the need for extended characteristics runs by associating one source with extended characteristics to other sources that may not have extended characteristics. By creating the association, each associated source receives a copy the characteristics. Go to **Setup** \> **Source Analysis** \> **Source Associations** to make changes once the source has been created.
