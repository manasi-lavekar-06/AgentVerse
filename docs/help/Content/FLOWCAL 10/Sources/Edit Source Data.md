# <span id="aanchor206"></span> Edit Source Data

Once a source has been created in FLOWCAL, you can make edits to the general source information or other data, such as the source analysis.

#### General Information

General source information, such as custom fields, validations, and other options, can be edited from the Quality Source Editor.

You can make the same edit across several sources from the Bulk Changes screen.

<div class="procedure">

To edit a source from the Quality Source Editor:

1.  Go to **Setup** \> **Source Analysis** \> **Gas Quality** or **Liquid Quality** and select a source using the Source drop-down.
2.  Click the **Edit** button.
3.  Populate required fields (highlighted in green). These fields must be populated before you can save your changes.

By default, Source Number and Reason are required fields; however, additional fields may be required based on how FLOWCAL options are configured.

1.  Enter any additional source information and click **Save**.

</div>

#### Source Analysis Data

Source data can be edited in the Quality Source Editor by selecting the **Source Analysis** tab and clicking the **New Detail** button.
