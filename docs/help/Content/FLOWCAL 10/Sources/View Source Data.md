# <span id="aanchor332"></span> View Source Data

Once a source has been created in FLOWCAL, you can view general information about the source or other source data, such as analysis.

#### General Information

General source information, such as custom fields, validations and other options, are viewable from the Quality Source Editor.

#### Source Analysis

Source analysis records can be viewed and edited from the Quality Source Editor. When enabled, this data is rolled up into hourly, daily, and monthly records, which can then be seen from the Source Analysis Rollups Viewer. This rolled data is primarily used for reporting externally and internally to other departments and downstream systems.

#### Quality

You can enter a sample Mole % or Mass %, and then have FLOWCAL calculate the other properties for the sample such as densities in different units, component Mass %, etc. All calculations are done according to the configuration in the Characteristics 1 tab for C6+/C7+ fixed ratio splits or Extended Characteristics. If set up accordingly, GPMs can be calculated using GPA 2172.

Calculations occur on import and edit and are saved only if the current values are missing or were previously calculated. If hand keying gas quality data, you must click the **Calculate** button.
