# <span id="aanchor144"></span> Tank Editor

This feature requires the **Liquids Inventory** module.

FLOWCAL supports the creation of upright cylindrical, horizontal, and spherical tanks, as well as editing tank characteristics and tank data in the Tank Editor. Capacity (strapping) tables can be manually entered or imported from a text file so that FLOWCAL can perform volume calculations based on reported levels. The tank inventory can be calculated and tracked based on meter measurement into and out of the tank, tank gauges and tank run tickets.

One of the most important pieces of liquids measurement is calculating and validating tank volumes for tank gauges and tank movements. This in turn allows for accurate GainLoss calculation as these tanks can be used in balance locations and calculating inventory.

All tank setup and designation details are available in the Tank Editor Configuration screen. Select the **Configuration** radio button to display the following tabs:

- [Main](Configuration/Tank%20Editor_Config%20-%20Main%20Tab.md)
- [Characteristics](Configuration/Tank%20Editor_Config%20-%20Characteristics%20Tab.md)
- [Units &amp; Options](Configuration/Tank%20Editor_Config%20-%20Units-Options%20Tab.md)
- [Site](Configuration/Tank%20Editor_Config%20-%20Site%20Tab.md)
- [BLM](Configuration/Tank%20Editor_Config%20-%20BLM%20Tab.md)

### Flow Data Screen Tabs

The Tank Editor Flow Data screen displays levels, tickets, and daily and monthly data. Adjusting the Start and End dates and clicking Refresh will display data associated with tickets that are currently attached to the tank for the specified time period. Double-clicking a record from the Gauging or Tickets tabs will open the associated ticket for viewing or editing.

Select the **Flow Data** radio button to display the following tabs:

- [Gauging](Flow%20Data/Tank%20Editor_Flow%20-%20Gauging.md)
- [Tickets](Flow%20Data/Tank%20Editor_Flow%20-%20Tickets.md)
- [Daily](Flow%20Data/Tank%20Editor_Flow%20-%20Daily.md)
- [Monthly](Flow%20Data/Tank%20Editor_Flow%20-%20Monthly.md)
