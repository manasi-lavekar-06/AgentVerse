## Custom Tab

The Custom tab contains eight user-defined string fields up 50 characters in length and eight user-defined numeric fields. Labels for these fields can be set on the Ticket Periodic Values tab of the [Custom Fields](../../Settings%20Manager/Application/Custom%20Fields.md) screen.
