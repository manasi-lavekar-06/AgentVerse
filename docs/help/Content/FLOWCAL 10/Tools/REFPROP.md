# <span id="aanchor42"></span> Reference Fluid Properties (REFPROP)

REFPROP is only used by FLOWCAL liquids. It is not used as a part of FLOWCAL gas.

Reference Fluid Properties (REFPROP), a program developed by the National Institute of Standards and Technology (NIST), calculates the thermodynamic and transport properties of industrially important fluids and their mixtures.

The calculation table is referred to as "REFPROP (NIST 23)" in the [Product Editor](../Settings%20Manager/Liquids/Product%20Editor/Product%20Editor.md) and as "REFPROP" in the [LQ Source Analysis editor](../Source%20Analysis/Liquid%20Quality%20Source%20Editor/Liquid%20Quality%20Source%20Editor.md).

## Licensing

Customers must purchase their own license to utilize this calculation table in FLOWCAL. It is not shipped with FLOWCAL. If a user selects to use REFPROP in FLOWCAL, but does not have the DLL installed, no calculations will occur.

## Installation

To install REFPROP:

1.  Purchase REFPROP from <a href="https://www.nist.gov/srd/refprop" target="_blank">NIST</a>.
2.  Copy the refprop.dll and the FLUIDS folder from the REFPROP installation into the Mathlibs folder everywhere FLOWCAL is installed.
3.  In FLOWCAL, select "REFPROP (NIST 23)" in the Product Editor or "REFPROP" on the LQ Source Analysis tab.
