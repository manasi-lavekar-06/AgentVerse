#### Alternate Periodic Tab

The Import Alternate Periodics option on the [Imports tab of the Meter Editor](../Meters/Meter%20Editor/Imports%20Tab.md) allows you to store data with an alternate periodic resolution. For example: You could use one set of data (e.g., hourly) for measurement calculations, but still bring in and view data at a different resolution (e.g., daily).

If Import Alternate Periodics option is enabled, FLOWCAL will import data in the Alternate Periodic data section of the CFX file if it is provided. The Volume Editor will display this Alternate Periodic tab when Flow Data records are selected. You can then double-click a row to access a detailed view of the data, but the data will not be editable.
