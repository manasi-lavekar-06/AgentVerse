# <span id="aanchor106"></span> Volume Editor Characteristic

### Meter Status

If a meter status is not specified, FLOWCAL will treat the meter as an active meter. Data can be imported and manually edited for disconnected or inactive meters. Only active meters will be rolled up or included in reports when run for a list of meters.

Meter status options are:

- Active
- Disconnected
- Inactive
- Non-existent
