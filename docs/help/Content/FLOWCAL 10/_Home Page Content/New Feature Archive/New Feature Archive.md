# <span id="aanchor101"></span> New Feature Archive

## Version 10.1.1.0

- [Balance Explorer](../../Rollup%20Viewers/Balance%20Explorer/Balance%20Explorer.md) - The new Balance Explorer combines several legacy rollup viewers: Daily Location Rollups, Monthly Location Rollups, NGL Balance, and Recovery Analysis Viewer.
- [Transaction Queue for Liquids](../../Settings%20Manager/Services/Transaction%20Queue.md) - The Transaction Queue service now includes functionality for liquids data in addition to gas data.
- [Density at Flowing Conditions (Liquid Sources)](../../Source%20Analysis/Liquid%20Quality%20Source%20Editor/Liquid%20Quality%20Source%20Editor.md) - The liquid source analysis import, editing, and apply processes have been enhanced to support liquid densities at sample conditions.

## Version 10.0.3.0

- [Live Oil Management Add-on](../../Meters/Meter%20Editor/Tools%20Menu.md) - The Live Oil Management form enables the ability to designate a liquid meter as a live oil meter. This form also allows dead oil and flash gas meters to be created and linked to a live oil meter.
- [New Location Volume Statement Reports](../../Reports/Report%20Descriptions%20and%20Tips/Meter-Location%20Reports.md#LocationVolumeStatement) - Four liquid versions of the Location Volume Statement report have been added that compile component composition, flow parameters and liquid quantities such as mass, GSV, NSV, and sediment and water for selected locations.

## Version 10.0.2.0

- [Original Meter Factor Validation](../../Meters/Meter%20Editor/Validations%20Tab.md#MeterFactorKFactor) - Meter factor and K-factor validations compare a meter characteristic value to a specified baseline range.
- [PPA Thresholds](../../Settings%20Manager/System/System%20Configuration/System%20Configuration%20-%20Thresholds%20Tab.md) - FLOWCAL now supports a set of minimum thresholds below which PPAs will be automatically rejected.
- [Location Validations](../../Locations/Location%20Editor/Tools%20-%20Location%20Validations.md) - Location validations help ensure that values fall within specified set points.
- [Exception Resolver](../../Exceptions/Exception%20Resolver/Exception%20Resolver.md) - The Exception Resolver now includes user settings, edit reason and note capabilities, and an object explorer view.

## Version 10.0.1.0

- [New Exception Resolver](../../Exceptions/Exception%20Resolver/Exception%20Resolver.md) - The Exception Resolver has been redesigned to align with FLOWCAL's updated UI standards and further our efforts to provide an optimal user experience.
- [Calculated Meter Enhancements](../../Calculated%20Meter%20Editor/Formulas%20Tab.md) - Functionality to support formulas is now available for calculated meters. This added flexibility allows users to define and expand arithmetic operators using conditional statements and defined criteria.
- [FMP Volume Tier](../../BLM/FMP%20Tier%20Calculation.md), [Heating Value Uncertainty](../../BLM/Heating%20Value%20Uncertainty%20Details.md) (BLM Compliance Updates) - Calculation functionality is now available for FMP Volume Tier and Heating Value Uncertainty. These capabilities help users maintain compliance with current BLM regulations.

## Version 10.0.0.0

- [Main Screen &amp; Menu Structure](../../Getting%20Started/Main%20Screen.md) - Our new interface has been designed and organized with the user in mind.
- [Customizable Dashboard](../../Getting%20Started/Dashboard.md) - The FLOWCAL Dashboard contains several tools to improve the user experience.
- [Bureau of Land Management (BLM)](../../BLM/BLM%20Compliance.md) - FLOWCAL 10 can help ensure compliance with BLM regulations.
