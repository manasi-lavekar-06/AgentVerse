# Learn FLOWCAL

Follow this sequence during new-joiner onboarding. Each module connects an explanation,
product help reference, visual, and practice activity where available.

<ol class="learning-path">
<li><strong>Orient:</strong> learn the product and its data journey.</li>
<li><strong>Model:</strong> understand systems, locations, meters, and sources.</li>
<li><strong>Operate:</strong> work with tickets, imports, validations, close, and PPA.</li>
<li><strong>Analyze:</strong> inspect rollups, reports, and exports.</li>
</ol>
