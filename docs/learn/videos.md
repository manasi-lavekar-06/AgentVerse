# Video Walkthroughs

Training videos become searchable learning modules when AgentVerse transcribes and
processes them. Each module will pair its transcript-derived guidance with the matching
help references and visual workflow.

## Planned Learning Series

| Training topic | Knowledge area |
| --- | --- |
| FLOWCAL Overview Demonstration | Start Here |
| Creating Systems, Users and Dbcolcheck | Platform Setup and Administration |
| Meters and Locations | Product Knowledge |
| List, Queries, and Bulk Changes | Daily Operations |
| File Imports, Rollups, and Tickets | Operations and Processing |
| Close and PPA | Daily Operations |
| Sources and Assignments | Product Knowledge |
| FcDataBoss and FcLoader | Processing and Integration |
| Reports and Exports | Reporting and Exports |

## Processing a New Video

Place its generated transcript in `transcripts/pending/`, then process it through the
AgentVerse workflow. The generated knowledge should be linked to the relevant module in
this series rather than appearing as an unclassified page.

Until the video catalog is processed, use the [guided data journey](../getting-started/flowcal-data-journey.md)
and [visual workflow](../visual/index.md) for the same conceptual path.
