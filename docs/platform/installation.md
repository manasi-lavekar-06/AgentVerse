# Installation and Database Tools

## Oracle Database

The imported FLOWCAL help corpus does not provide an Oracle installation runbook. Treat
Oracle installation, patching, backups, and database account provisioning as platform
team-owned work. Before starting FLOWCAL services, confirm the approved Oracle version,
database name, service account, connection string, and backup/restore ownership.

## FLOWCAL Application

Once the approved database environment is available, use the service configuration guide
to install and configure FLOWCAL services.

[Install and configure services](../help/Content/FLOWCAL%2010/Admin%20Options/Install%20%26%20Configure%20Services.md)

## SQL Developer

Use the approved client version and a least-privilege account. Keep connection profiles
outside shared documentation and follow the environment's credential-management policy.

> This page is an onboarding pointer, not a replacement for controlled installation
> procedures. Add the approved team runbook here when it is available.
