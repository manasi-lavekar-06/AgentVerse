# FLOWCAL Flashcards

<div class="flashcard-deck" data-color="teal" tabindex="0">
  <div class="fc-card" data-term="System" data-category="Entity">An organizational boundary in FLOWCAL. Systems contain the locations used to model operations.</div>
  <div class="fc-card" data-term="Location" data-category="Entity">An operational place within a system. A location can have one or more meters.</div>
  <div class="fc-card" data-term="Meter" data-category="Entity">A physical device that measures product volume and provides data to FLOWCAL.</div>
  <div class="fc-card" data-term="Ticket" data-category="Operation">A point-in-time record whose values are entered manually rather than read from continuous meter data.</div>
  <div class="fc-card" data-term="Validation" data-category="Control">A check that evaluates incoming data. Failed data creates an exception that must be resolved.</div>
  <div class="fc-card" data-term="PPA" data-category="Control">Post-processing approval used for changes to data that has already been closed.</div>
  <div class="fc-card" data-term="Rollup" data-category="Processing">The aggregation of detailed data into higher-level results used for analysis and reporting.</div>
</div>
